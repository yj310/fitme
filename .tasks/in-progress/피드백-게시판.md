친구들이 앱 안에서 피드백(버그·제안)을 사진과 함께 올리고, 관리자가 접수 · 해결 중 · 해결됨 · 보류로 관리하는 게시판.

- [x] 다른 서비스 디자인 조사 (Trello·Linear·GitHub Issues·Canny·Featurebase·Frill·Userback·BugPin)
- [x] HTML 시안 4개 (`docs/design/feedback-board/`: A 칸반 · B 목록+상세 · C 공감 게시판 · D 제보 버튼)
- [x] 사용자가 시안 고르기 → D(어디서나 제보 버튼) + B(목록 + 상세 관리 화면)
- [x] DB: `board_posts`·`board_comments` + RLS·컬럼 권한, 비공개 `board` 버킷, 관리자는 `ADMIN_USER_IDS` (마이그레이션 `20261118000000_board.sql`)
- [x] API: 글 쓰기·내 피드백·새 소식 읽음·덧붙이기, 관리자 목록·상태 변경·답변, 사진 업로드 URL (테스트 5개)
- [x] 웹: 오른쪽 피드백 버튼(지금 화면 캡처 자동 첨부), 피드백 관리 화면, 사진 붙여 넣기·끌어다 놓기
- [x] 테스트·문서·보안 점검 (로컬 계정 A·B로 확인, PostgREST 직접 우회 5가지 막힘)

- [ ] 배포 후 운영에서 확인

## 결과 요약
