## 결과 요약
- API 테스트 43개 통과, 오프라인 평가 30개 요청: ID 유효성 100% · 제외 재추천 0건 · 3개 생성 100%.
- 웹 빌드·린트·타입 검사 통과 (12개 경로). 실제 Supabase·AI 키 연결 후 브라우저 확인은 아직.
- 2026-11-07 실제 키 연결: 개발 모델을 `nemotron-3.5-super-vl`로 교체(`kimi-k2.6` 404). 실제 평가 p50 4.8초, AI만으로 3개 생성 90%, 태깅 카테고리 100%·색 87%. 실제 연결에서 나온 버그 4건 수정.
- 2026-11-07 품질 점검: 실제 AI로 대화 14개(데이트·출근·결혼식·면접·산책·회식·여행·오늘의 코디 칩 등) 돌려 15건 발견·수정. "2번 신발만 바꿔줘"는 AI 호출 없이 0.7초, "왜?"·"1번 좋아"는 새로 짜지 않고 답함, "원피스로/블레이저 넣어줘" 오작동 수정.
- 2026-11-14 정식 배포: 운영 평가(flash-lite, 요청 30개) ID 유효성 100%·제외 재추천 0건·AI만으로 3개 90%·p50 3.5초. 카카오 로그인은 Supabase가 이메일 항목을 항상 요청해서 이메일을 선택 동의로 두고 이메일 없는 가입을 허용 (결정 12). 본인·친구 계정 로그인 확인.
- 2026-11-15 취향·추구미 합침: 온보딩 3단계(내 몸 → 내 추구미 → 옷 등록), 추구미 만들기·고치기는 온보딩과 같은 단계 화면, 에이전트는 추구미만 사용. API 테스트 78개 통과, 개발 계정 B로 온보딩·추가·대표 변경 확인.
- 남은 일: 운영 사이트에서 옷 등록→코디 추천 전체 흐름 확인, 시드 사진 3장.
