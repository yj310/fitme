## 구현 중 정한 세부 사항 (요구서 범위 안의 해석)

- **추가 테이블:** `conversations`(대화 단위 누적 조건), `chat_messages`(최근 대화 이어보기). 요구서에 `conversation_id`만 있고 저장 테이블이 없어서 추가.
- **추가 컬럼:** `users.avoid_subcategories`(온보딩 '피하는 아이템'), `users.region_code`, `users.avatar_url`, `outfits.rank`·`label`·`favorited_at`, `agent_runs.source`·`is_free_tier`, `outfit_items.user_id`(RLS용).
- **feedback_type `reroll`:** '다시 짜기' 기록. 개인 선호도의 "최근 다시 짜기 조합 감점"에 사용.
- **API 데이터 접근:** 서버는 PostgREST를 **사용자 본인 JWT로** 호출해 RLS가 항상 적용되게 함. 서비스 키는 날씨 캐시·계정 삭제·AI 키 저장에만 사용.
- **태그 코드:** DB에는 영문 코드(예: `knit`, `ivory`), 화면에는 한글. 전체 목록은 `api/app/domain/taxonomy.json`.
- **색 계열(톤온톤 판단):** mono(블랙·화이트·그레이·차콜), warm_neutral(아이보리·베이지·브라운), blue(네이비·데님 블루·블루·스카이블루), green(그린·카키), red(레드·핑크), purple, yellow(옐로·오렌지).
- **추구미 프리셋 6개:** 자연스러운 미니멀, 프렌치 시크, 캐주얼 스트릿, 단정한 오피스, 러블리 페미닌, 아메카지.
- **상황(occasion) 표준값:** 소개팅, 데이트, 출근, 회의, 면접, 학교, 친구 모임, 가족 모임, 결혼식, 여행, 운동, 쇼핑, 일상. 그 외는 사용자 표현 그대로.
