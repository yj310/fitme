각 시안 위쪽 막대에서 관리자 화면과 사용자 피드백 버튼을 바꿔 볼 수 있어요.

지금 디자인에서 걷어 낸 것

  • 이모지 아이콘🐞 💡 💬 🖼 대신 선이 얇은 아이콘 한 벌만 써요.
  • 색 칠한 알약 칩상태·종류·빠른 답변이 전부 색 배경 알약이었어요. 상태 색은 작은 아이콘에만 쓰고 나머지는 글자로만 보여 줘요.
  • 상자 안의 상자테두리 카드를 겹겹이 쓰지 않고, 여백과 가는 구분선으로 나눠요.
  • 설명 문장"끌어다 놓기, 클릭, 스크린샷은 ⌘/Ctrl+V (0/5)" 같은 안내를 아이콘 하나와 짧은 한 줄로 줄였어요.
  • 세로 글씨 탭화면 오른쪽에 세로로 붙은 '💬 피드백' 대신 실제 서비스처럼 오른쪽 아래 버튼을 써요.
  • 단축키 안내 상시 노출J/K·1–4 단축키는 그대로 두되 화면에는 메뉴 안에서만 보여요.
  • 글꼴과 남색 강조색IBM Plex 대신 국내 서비스에서 많이 쓰는 Pretendard, 강조색 대신 검정 버튼 하나.
