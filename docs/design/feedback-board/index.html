피드백 게시판 시안 4개

FITME 앱 안에 들어갈 화면이에요. 각 시안 위쪽 검은 띠에서 사용자 화면 / 관리자 화면을 바꿔 볼 수 있어요. 데이터는 예시이고, 사진 올리기(끌어다 놓기·클릭·붙여 넣기)와 상태 바꾸기는 실제로 눌러 볼 수 있어요.

모든 시안에 공통으로 들어가는 것
  • 상태 4가지: 접수 해결 중 해결됨 보류. 바꿀 수 있는 사람은 관리자뿐이에요.
  • 종류: 🐞 버그 · 💡 개선 제안 · 💬 기타
  • 사진: 최대 5장. 끌어다 놓기, 클릭해서 고르기, 스크린샷 ⌘/Ctrl+V 붙여 넣기 모두 돼요.
  • 자동 기록: 어느 화면에서 남겼는지, 기기·브라우저
  • 관리자 답변: 남긴 사람이 볼 수 있고, 상태가 바뀌면 알림이 가요.
