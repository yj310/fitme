피드백 게시판 스타일 시안

화면 구성과 흐름은 지금 그대로 두고, 생김새만 세 가지로 바꿨어요.
각 시안 위쪽 막대에서 피드백 관리와 피드백 버튼을 바꿔 볼 수 있어요. 목록 고르기, 상태 바꾸기(1–4, J/K), 내 피드백 펼치기도 눌러 볼 수 있어요.

오른쪽 가운데 피드백 탭 → 남기기 / 내 피드백 패널 · 종류 3개 → 내용 → 화면·캡처 안내 → 사진 → 보내기 · 내 피드백의 진행 막대와 덧붙이기 · 피드백 관리의 검색, 상태 탭 5개, 목록, 상태 버튼 1–4, 남긴 사람·화면·기기, 본문, 사진, 기록, 빠른 답변, 답변 보내기. 문구도 지금과 같아요.
